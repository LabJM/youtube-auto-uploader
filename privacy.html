Privacy Policy: Youtube Auto Uploader

Last updated: October 10, 2026

Youtube Auto Uploader is a private tool that Everwhy Studio uses to manage its own YouTube channels. It is not offered to the public.

What the app accesses

When a channel owner connects a YouTube channel, the app uses YouTube API Services to upload videos, set titles, descriptions, captions and thumbnails, and read that channel's public and analytics data.

How data is stored and used

Access tokens and channel data are stored only on the channel owner's own computer. The data is used only to run the owner's channels. It is never sold, shared with third parties, or used for advertising. It is kept until the owner disconnects the channel.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

You can remove the app's access at any time at myaccount.google.com/permissions. Disconnecting a channel in the app also removes its stored token from the computer.
